# 消息、AI、个人与运营 · UI 功能对照

日期：2026-10-09。范围以当前组件及真实业务事件为准；不改 API、运营 iframe 内站或共享状态所有者。

## 版式与材料

- 协作消息：会话标题与身份操作共享主对齐线；真实协作计数折叠保存；白底时间线占据剩余高度；固定在面板底部的编辑区不随消息滚动。对方灰白、自方浅蓝，正文 14–15px、时间与已读 12px。
- AI 聊天：标题、回答与输入区使用同一内容列。回答正文行高 1.75；商品从横向小卡片改为可比较图文行，手机单列；推荐问题为具名行。
- AI 额度：模型与状态为首要信息；今日用量、剩余本地预算、到期日形成稳定数字列；手机按标签与右对齐数值独立重排。三项已有用途有明确任务入口，规则延后展开。
- 管理者：具名身份页签、身份摘要、三项真实统计、消息与切换操作。圆形头像保留身份辨识，其余内容以分隔组织。
- 运营：窗口标题与工具栏分层；保留四项真实窗口操作，iframe 内容为独立实白阅读面。
- 使用既有系统字体、品牌蓝和语义色。4/8 基础节奏，控件使用 `--ui-control-radius`，控件至少 44px。无新依赖、无新的模型调用。
