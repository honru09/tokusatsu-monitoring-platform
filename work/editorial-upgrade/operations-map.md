# 工具与业务工作区 · 功能对照

日期：2026-10-09。文件范围：库存订单、监控配置、利润与物流、进货计算器、资讯专区，以及 `operations-editorial.module.css`。未改全局导航、API 请求地址、交易提交内容、AI 用途和后台计划。

## 版式与信息优先级

- 库存订单：第一眼看商品、成本、剩余库存、回款和利润。桌面 >=1180px 采用六列台账；手机改为图文身份和两列指标，卖出操作独立保留。完整商品名、采购备注与销售/调整历史仍在详情。
- 监控配置：关键词库承载主要扫描任务，分类轨承载过滤与组织。标题、搜索、列头与记录共用对齐线；手机分类先于关键词，可快速限定范围。分类数量与关键词运行数取真实数据。
- 利润与物流：左侧是收藏/已购选品清单，右侧是实际承运商、费用、商品参数和结果台账；手机独立纵向排列。预估与实际值仍保留业务区别，所有现有编辑和计算入口保留。
- 进货计算器：商品与售价 → 报价参数 → 客户结果与上限。实际收益视图保留同一草稿与客户报价同步。金额右对齐，完整大金额可换行，报价与实际支出不混合。
- 资讯专区：标题、更新状态、检索/类型筛选 → 编辑式资讯索引 → 完整正文浮层。桌面表格用于横向比较，手机索引保留类型、来源、日期、标题、作者。

## 动效清单

| 场景                         | 反馈 / 结束条件                                              | 减少动效                 |
| ---------------------------- | ------------------------------------------------------------ | ------------------------ |
| 库存状态、报价视图、资讯类型 | Motion 选中背景连续移位，真实筛选/切换即时启动               | duration=0，状态同等可达 |

| 监控运行/扫描                | 原按钮禁用与真实 pendingRows 行状态反馈，请求结束恢复        | 短 opacity 反馈          |
