# 工具与通讯交互增强

## 新增 7 类真实状态联动

1. **库存订单回执**：新建、出售、调整收到成功响应后，显示薄荷色保存回执。失败时表单与输入保留。
2. **物流参数保存链路**：各商品参数显示待保存、保存中、已保存、失败；输入保留。计算使用同步请求锁，连续点击不重复执行。等待期间修改参数或商品选择时，不展示过期利润结果。
3. **资讯查询恢复**：无结果可清除搜索与类别，并返回搜索焦点；失败可重试。查询切换取消旧请求，避免旧结果覆盖新条件。
4. **消息回复上下文**：已载入的文本回复引用定位并聚焦原消息，局部薄荷色强调；指针原生连续滚动，键盘与 reduce 即时。回复、转发、移除引用返回输入焦点，保留文字草稿。
5. **助手阅读与详情**：商品详情打开时展示真实等待状态并阻止重复请求；失败重新开放入口。阅读旧内容时新答案不抢滚动位置，出现“新回答已就绪”入口。
6. **AI 用途入口**：读取、翻译、聊天行的焦点、悬停、按下材质与方向反馈；保持现有导航，未新增模型调用。
7. **运营重连回执**：postMessage 已发送后显示真实“已发送重连请求”；不宣称连接成功，不重建 iframe，展开和收起保留会话。

## 动画所有权

- 现有共享 Apple springs 保留，普通 CSS pressure 保留。
- 资讯 Motion 按钮标记 `data-apple-motion-owned`，并排除局部 CSS pressure。
- 助手新答案、消息上下文与工具条、AI 用量条、库存回执显式标记 Motion owner。
- 与全局 `html[data-apple-input="keyboard"]` 衔接，键盘取消位移与缓动；reduce 保留立即可用的状态。
- 移除助手整块外框，只保留输入区材质与消息层次。
