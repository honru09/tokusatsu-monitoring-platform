## 任务一致性

- 默认全局暂停，自动收录 / 生成 / 发布 / 指标同步默认关闭。监测任务默认不启用。
- 自动发布在数据库领取任务时重新核对计划时间、商品版本、货源状态、审核条件、人工接管与每日请求额度。
- 监测扫描使用持久化租约，修改监测条件与任务领取经过数据库锁。登录、验证或限流响应停止该监测任务；失败不会被算成零结果。
- 每个商品同一时间只能安排一个未完成的维护任务。自动维护重新核查版本、货源、目标商品、管理者和渠道能力。人工接管停止后续自动操作。
- 发布 / 下架 / 维护已经发送的请求用持久化令牌作为幂等键。超时或重启后的未知结果转为人工核实，不自动重发。执行中的维护任务及待核实维护结果会阻止冲突的发布 / 下架 / 回填操作。
- 本系统每件商品每天最多安排一次擦亮；每日发布请求默认 30。这是软件配置，实际平台额度以账号为准。
- 渠道指标带实际商品 ID 与观测时间；未知值保持为空，同一观测时间去重，旧商品的数据不会合并进新商品的最新汇总。

## 搜索连接

```dotenv
RESALE_MARKET_SEARCH_URL=
RESALE_MARKET_SEARCH_TOKEN=
```

留空时沿用 `XIANYU_SEARCH_API_URL` / `XIANYU_SEARCH_API_TOKEN`。两个端点的令牌分别使用对应配置。

`POST {url}`，可选 Bearer 令牌，JSON：`{"keyword":"关键词","limit":50,"maxItems":50}`。返回商品数组，或 `{items:[...]}` / `{results:[...]}` / `{data:{items:[...]}}`。商品需提供标题、人民币价格、实际闲鱼商品链接及一致的商品 ID。兼容仓库的 `id/title/price/area/link/image_url` 字段。

## 卖家操作连接

继续使用 [发布桥接协议](RESALE_WORKSPACE.md)。以下均为本项目协议，需要连接端适配实际渠道，配置地址不等于已经验证实际平台权限。

```dotenv
RESALE_PUBLISHER_URL=
RESALE_PUBLISHER_TOKEN=
RESALE_PUBLISHER_CAPABILITIES=
```

只有连接端确实支持时，在能力列表中填入 `bump,reprice,metrics` 中相应项目。

- 维护：`POST {base}/seller/items/{targetItemId}/actions`。
- 请求：`action`（`bump` / `reprice`）、`targetItemId`、`operationToken`、调价时的 `priceCny`。
- 请求头：Bearer 令牌及 `Idempotency-Key: <taskId>`。
- 成功回执：`{"status":"succeeded","targetItemId":"实际ID"}`；调价回执还需包含与请求一致的 `priceCny`。
- 指标：`GET {base}/seller/items/{targetItemId}/metrics`。
- 指标回执：实际 `targetItemId`、ISO `observedAt`、`views/wants/orders/revenueCny`。未知字段省略或使用 null；至少一项是真实数值。
- 连接端按令牌去重，处理图片上传、字段转换和实际账户授权。服务端令牌不进入浏览器。

普通账号当前可通过本机官方浏览器搜索、上传图片并填写发布表单。正式发布需用户确认；擦亮、调价、指标读取的自动接口仍需实际授权渠道，本模块提供人工清单与核实入口。本轮未接买家订单、采购支付、自动交付或多账户管理。
