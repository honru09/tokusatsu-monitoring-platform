# 移动操作层修复

用户明确要求：入口只保留名称；右上角精简；两个悬浮窗可移动；底栏贴底无缝；软键盘不挤动全页面。

- 继承 Apple 系统字体与液态玻璃，实际变化为统一44px图标、单一工具组、无包围盒汇率、贴底导航材质，移除重复状态/数字身份。
- 历史/砍价共享同一拖动 hook，直接拖动或长按可开始，pointer capture、点击抑制、边缘吸附、持久化与视口边界。44px最小命中，默认左侧中下和右侧中上，避开输入和导航。
- 控件定位层在主壳中独立于聊天动画和overflow容器；模态层仍高于控件。
- 手机底栏bottom:0，包含安全区，最底不透出正文。软键盘打开时底栏暂隐而不是上移；聊天输入贴键盘上方，消息区域独立滚动。键盘关闭原位恢复。使用 visualViewport，不阻止系统缩放。
- 输入支持中文组合输入，手机Enter换行、桌面Enter发送，自动增高至五行；点击发送保持键盘与焦点。
- 闲鱼诊断仅只读：部署开关全部false，未配置数据提供者，comparison/机会/run表均0；不能把筛选页0件宣称持续运行。需要搜索服务/Apify、费用与授权后才能开启后台任务。此轮不自动启用计费爬取。
- 验收：真实触摸事件拖动两个控件、持久化重载、贴底几何、模拟键盘viewport、IME与回车、无写入真实聊天/购买；Web测试与生产构建。
