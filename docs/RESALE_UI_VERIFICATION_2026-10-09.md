# 闲鱼模块操作简化验收

日期：2026-10-09。网站：[闲鱼上架](http://localhost:3000/?workspace=resale)。

## 已部署的调整

- 底部只有一个黄色主动作，边缘、内侧高光和轻阴影提供按钮层次。未完成编辑时保存，确认商品条件后去闲鱼发布；有修改时先保存，再使用返回的新版本准备官方表单。需要独立保存时提供低调的文字入口。
- 刷新、自动化设置和任务开关收进页面更多菜单。审核、接管、核查、暂停和入队放入更多商品操作。已登录时打开闲鱼位于连接详情。
- 图片工具与链接集中到管理图片，默认收起。桌面图片由 4 列改为 6 列，手机保持 3 列；编辑与预览使用文字选中线。
- 商品阅读面保留清晰内容层次，减少等权按钮、重复框线与常驻说明。未选择商品时隐藏批量面板；手机编辑时集中显示商品。

## 功能衔接

一键登录已有真实状态检查和官方扫码入口。普通账号实测搜索取得 3 个有效商品。默认包邮，所在地沿用账号选择；默认值和单件发货设置均可人工修改。

当前闭环为：货源候选 → 收录 → 人工编辑 / 商品读取 / 翻译 → 保存 → 官方表单准备 → 用户确认发布 → 粘贴闲鱼链接记录结果。监测发现、维护清单和实际运营指标与商品管理相连，缺少自动渠道能力时显示人工入口。

实际发布仍需在闲鱼官方页面确认。已验证官方图片上传与价格、运费填写，未提交测试商品；买家订单、自动采购付款与自动交付没有经过验证。

AI 仅启用智谱 `glm-5.3-flash`，用于商品读取、翻译和聊天；后台模型调用关闭，没有付费回退。赠送资源使用本地 1400 万 tokens 预算、每日 20 万上限，截止 2026-11-09 14:35:56 +08。本轮三种真实用途合计消耗 5090 tokens，本地剩余 13,994,910；本页不是供应商实时余额。模型使用赠送额度，并非永久免费。

## 设计依据

开发前明确一个主要动作与按需展开的工具，沿用 ENERGY 3 / RHYTHM 3 / MOTION 3。商品图和价格负责识别，黄色负责当前动作，白色编辑面负责阅读，浮层阴影负责说明层级。系统字体适合中日文商品信息；输入框、图片、按钮和文字页签采用不同边界处理。按压反馈为 180ms / 0.98，键盘和减少动态模式避免额外缩放。
