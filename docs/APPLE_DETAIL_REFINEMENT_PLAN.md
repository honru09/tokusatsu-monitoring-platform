# 全站简化与商品详情重做

阅读定位：面向高频采购人员的 Operate 界面，继承 Apple 系统字体、白底黑线 Logo 与液态玻璃。简化信息层级而非删功能。

| 原表现 | 本轮表现 | 原因 |
| --- | --- | --- |
| 横幅式图片与四格重复价格 | 适配照片比例的大图、单一价格主视线 | 首先看清商品与费用 |
| 详情全部堆在一列 | 商品概览 / 可展开明细 / 固定操作 | 阅读与行动不互相挤压 |
| 纠错默认占整屏 | 折叠编辑入口，失败可重试 | 非编辑任务不占据阅读空间 |
| 文本、字段、卡片多重嵌套 | 分组行、细分隔、常规字重 | 清楚而不密集堆框 |
| 重复说明和英文技术标题 | 简洁中文标题，必要说明按需查看 | 可直接操作，不做教程 |

## 结构与数据

保留 Dashboard 的数据与翻译请求。DetailDrawer 保留焦点、历史返回和保存回调。
新增共享 DetailDisclosure 与 DetailDescription（client），采用原生 details 与渐进展开，完整内容不截断删除。
图片、平台、商品名、标价、数量、品相、邮费为概览；完整描述默认预览，明细、闲鱼、AI、SHF和纠错收起。
主价格使用原标价，不用未知国际运费推算总到手价；已知费用按原证据显示。
纠错保留持久化审计，补充保存失败状态和无效数量检查，不暴露后端内部错误。

## 系统覆盖

首页/在售、链接、收藏、卖家、购买记录、库存订单、个人页、聊天、AI助手、AI状态、物流、计算器、不感兴趣、监控、设置：共享更轻的玻璃层次、系统数字字体、统一分组标题与可触控控件。文字简化只针对界面说明，商品/新闻正文、业务数据不删。

## 动效与可访问

玻璃用于工具栏、底部操作与模态层级；阅读区稳定。详情入场采用小幅弹簧，文本不闪烁，减少动态效果时静态。
详情自身滚动，不让全站导航覆盖操作。大字体、320px与短屏允许滚动；Tab不能进入折叠明细的隐藏表单。

## 验收

统一完成后跑 Web测试、类型与生产构建；批量检查主要工作区390/1440px、详情320/390/768/1440px、长标题/多图/缺失翻译/竞拍/保存失败/折叠焦点。资料正文、原页和发送入口必须仍可达。浏览器不写真实购买和分类记录。
