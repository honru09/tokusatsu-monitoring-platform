# Mercari 转闲鱼模块

入口：工作台 → 闲鱼上架，或 `?workspace=resale`。

## 已接入的流程

- 复用现有 Mercari 监测和状态刷新。货源候选只取已确认在售的直购商品，排除已购、忽略和归档商品。模块匹配范围仍受采购平台现有采集范围影响。
- 按关键词和日元价格范围筛选候选，单个收录或收录本页；可开启后台自动收录。
- 每个货源只创建一个持久化草稿。首次建议售价按配置的汇率、已知邮费、额外成本及加价比例计算；默认汇率是可编辑参数，并非实时汇率。未知运费不会自动变成已确认费用。
- 中文草稿复用已有译文；人工整理未译商品时使用受额度限制的商品翻译。后台只整理完整译文，不请求模型。当前只启用智谱 `glm-5.3-flash`，没有付费备用，生成失败保留原稿。
- 人工编辑标题、完整描述、人民币价格、图片链接和顺序、交付说明；保存自动接管该商品。生成结果有版本检查，不能覆盖稍后保存的人工版本。
- 人工确认图片/信息使用权、完整成本及履约能力，然后审核。自动发布只处理已审核并明确加入队列的商品。
- 人工可接管、交回自动流程、暂停商品、复制上架文案、粘贴闲鱼链接自动识别商品 ID、核实下架结果。
- 切换采购平台工作区时保留当前编辑器，隐藏时停止轮询。切换编辑商品时如有未保存修改，提供继续编辑或放弃后切换。版本冲突和保存失败保留输入。

## 自动化状态与保护

初始状态是全局暂停，自动收录、生成及发布都关闭。恢复自动任务不等于开启各项开关。

API 每60秒执行一轮，单轮最多收录50件、生成3件、发布5件。数据库保存队列及人工生成请求，进程重启不丢草稿和队列。多个 API 实例通过记录版本、生成令牌和数据库锁避免重复外部发布。

每日发布额度由卖家配置，默认30，**仅为软件初始设置，不是平台公布的安全数量或账号额度**。按北京时间统计已发送请求；失败但无法核实的请求也占额度，人工首次回填发布结果计入统计。额度锁覆盖并发发布。

发布前要求：确认在售、直购、未归档/忽略、价格及邮费与审核快照一致、最近可靠观测未超时、草稿审核条件完整。默认观测有效期10分钟，可配置1至120分钟。核查复用 `item-status-refresh` 采集队列；这是平台的可靠观测时间，不代表已锁定上游库存。仍可能在观测后被其他人买走。

已审核或入队的货源变价、售出或下架，商品会被拦截并要求人工重审。状态未知或观测过期不会被解释为已售出，先重新核查。已发布商品发现明确不可用会提示下架；全局未暂停、商品未人工接管且来自发布桥接服务时可以自动下架。人工发布的商品需人工下架。人工接管停止自动生成/发布/下架，仍保留货源状态提示。

已发出的外部请求不能通过“暂停”撤销。发布/下架失败、超时或后台重启后未取得确认，进入“结果待核实”，不会自动再次发送；先到闲鱼检查，再回填实际结果。请求本身用持久化操作令牌作为幂等键。

## 当前闲鱼连接能力

普通账号已通过官方扫码登录，本机浏览器连接可以读取真实登录状态、搜索商品，并打开和填写官方发布表单。独立保存的浏览器会话由本机 bridge 管理；登录过期、验证码或地点选择仍由用户在官方页面处理。

当前流程：选货源 → 收录 → 编辑/翻译并核对商品 → 确认图片与履约条件 → 去闲鱼发布（有修改时先保存）→ 官方表单填入图片、文案、价格和发货设置 → 用户确认发布 → 粘贴商品链接记录结果。审核和自动队列放在更多商品操作中。

本机表单准备会复用同一商品版本的页面，保留已经进行的人工修改；保存失败不会打开发布页。填写或图片上传失败保留官方页面供人工继续。当前尚未验证自动点击正式发布与回执，自动发布渠道仍未连接。

自动发布入口使用 `ResalePublisher` 适配层，等待连接实际可用且经过授权的发布渠道。环境变量放在服务端，界面不接收或返回令牌：

```dotenv
RESALE_PUBLISHER_URL=https://your-private-publishing-bridge.example/v1
RESALE_PUBLISHER_TOKEN=server-side-token
```

上面的地址是协议示例，不是现成服务。接上经过验证的闲管家/其他发布接口时，需要在桥接服务中把以下协议转换成该渠道的实际请求、字段和权限。

### 本项目桥接协议（不是闲鱼官方接口）

- `PUT {base}/listings/{internalListingId}` 发布。
- `DELETE {base}/listings/{internalListingId}` 下架。
- `Authorization: Bearer <token>`；`Idempotency-Key: <operationToken>`。
- JSON 请求：`action`, `operationToken`, `id`, `version`, `title`, `description`, `priceCny`, `imageUrls`, `deliveryText`, `sourceUrl`, `targetItemId`。
- 桥接服务必须按内部 listing ID 保存目标商品映射、按 operationToken 去重，重放同一操作应返回同一结果，不能重复创建商品。
- 发布成功：`{"status":"published","targetItemId":"实际商品ID","targetUrl":"https://www.goofish.com/item?id=实际商品ID"}`。
- 下架成功：`{"status":"withdrawn"}`。
- 服务端只接受经过校验的闲鱼 HTTPS 链接；未收到符合协议的确认时视为待核实。
- 桥接 URL 不开放给买家输入；服务凭证只经服务端 HTTPS 或受控本机网络传输。配置不等于验证连接，实际请求结果才会确认发布能力。

## 数据及接口

新增三张表：`resale_settings`、`resale_listings`、`resale_events`。与采购 `Item` 关联，不改采购记录、库存或订单逻辑。迁移：`20261009120000_resale_workspace`。

API 前缀 `/resale`：列表、候选、单件详情、收录、编辑、设置、执行一轮、商品 actions。所有变更校验现有 active 管理者身份，沿用当前平台的身份选择机制。商品变更要求 `version`；详情含最近100条记录。

第一版单个闲鱼销售账户，支持两位管理者协作。采购下单、付款、国际物流、买家订单和自动交付未包含在本次模块中。

## 验证

- PostgreSQL 集成测试在专用 `resale_test` 数据库执行，覆盖重复收录、编辑冲突、并发发布、防止盲目重试、货源变更、每日额度、进行中接管及过期 AI 结果保护。
- 规则测试覆盖状态未知、失效观测、邮费变化、拍卖过滤、审核确认和日界线。
- 新迁移在独立 PostgreSQL 数据库从全部历史迁移完整执行过。
- 1440px桌面与390px手机浏览器通过编辑、保存失败保留输入、切换工作区保留输入、收起设置保留输入、审核与暂停、44px控件及无横向溢出检查。浏览器交互使用测试夹具，不向闲鱼发请求，不写入正式商品数据。
- 当前本地 Docker 的 API/Web 已更新，正式库仅应用新增迁移；实际候选接口读取现有监测商品。自动任务维持初始暂停、自动发布未连接。
- 项目现有 `21st` 目录搜索需要登录，此环境未登录，因此复用现有工作台与编辑器视觉规范，没有拉取外部组件。

## 2026-10-09 闲鱼界面参考与编辑优化

参考来源为实际查看的[闲鱼官方网页](https://www.goofish.com/)和[发闲置入口](https://www.goofish.com/publish)。本轮在已登录普通账号中核对了真实发布表单、图片缩略图、价格和发货设置，并用自有测试图片验证填写后移除。未发布测试商品；原生手机端动画参数仍需脱敏录屏进一步校准。

平台使用系统字体、白色阅读面和现有导航。黄色集中用于一个主要动作和图片封面提示；红棕色突出售价，不表示操作失败。设计强度沿用 ENERGY 3 / RHYTHM 3 / MOTION 3。

- 状态使用单个筛选入口，商品列表优先展示图片、标题和售价。没有选择商品时不展示批量面板。
- 编辑按图片、商品信息、售价与交付排列；支持选择封面、前移/后移、移除及恢复货源图片。链接输入保留，没有新增本地图片上传服务。
- 商品预览展示当前草稿、图片切换、价格及交付说明，并明确不是闲鱼发布结果。切换预览不会丢失输入。
- 手机选择商品后显示独立编辑视图，返回列表和再次进入保留修改；桌面继续并列列表与编辑器。
- 底部只保留一个醒目主按钮；满足确认条件后可直接去闲鱼发布，有未保存修改时自动先保存。必要时显示低调的保存入口。审核、接管、暂停、核查和入队集中到更多商品操作；图片操作默认收起；刷新、设置和任务开关集中到页面更多菜单。
- 复用 `motion-tokens.ts`：指针按压采用0.98缩放反馈，预览进入仅180ms透明度变化。键盘切换不增加入场动画；减少动态时移除缩放并服从全局动态设置。没有持续播放、价格跳动或为等待添加的人工延时。

浏览器验证使用明确标记的界面测试数据，覆盖图片排序/移除、预览保存、返回保留输入、保存失败、工作区切换、设置折叠、审核暂停、减少动态、44px目标和页面溢出；不会收录真实商品或向闲鱼发布。

后续最有帮助的信息：脱敏闲鱼操作录屏、2～3个首批Mercari商品链接、完整成本和交付规则。自动发布渠道的授权/字段能力在接入阶段另行核实，聊天不接收账号密码或Cookie。

默认发货使用包邮，所在地沿用闲鱼账号选择。用户可以在设置中修改默认值，或展开单件商品的运费与所在地修改包邮、固定运费、按距离计费、无需邮寄和地点。账号没有默认地点时，首次需在官方页面选择一次。
