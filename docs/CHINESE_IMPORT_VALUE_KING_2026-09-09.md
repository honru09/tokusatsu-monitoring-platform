## 2. 无需光标的一键导入

- 发布辅助和输入辅助均有“一键导入”。第一行标题、余下正文，保留段落。
- 新page-import端点无需预先scanId，点击时重新查找唯一的有效编辑页。
- 标题与正文必须各识别到一个；当前可见的编辑页优先，多页歧义时拒绝猜测。
- 自动激活标签、定位并选择字段，再使用真实Input.insertText写入；不是往当前光标位置随便粘贴。
- 支持标准输入框、textarea、富文本及plaintext-only编辑器；导入后读回核对。
- 尚未上传素材、编辑器未出现或字段不唯一时给出明确提示。导入不等于自动发布。
- 导入期间暂禁远程指针/快捷键干扰，内置文案仍可编辑并保留新修改。

## 3. 性价比之王不依赖闲鱼

已移除列表查询、首页统计、响应判断中的闲鱼必备门槛。已有闲鱼证据仍可补充，没有闲鱼时可用独立规则入选；现有商品与以后入库的商品使用同一读时判断，无需等待闲鱼队列或额外回填。

共同条件：直购、在售、线上、未购买/未忽略/未归档；已知邮费；明确数量；有图片和足够描述；正常品相与特摄身份；24小时内有效观察。不收垃圾品、仅配件/空盒、预约、卡片及明确破损/缺件。

初始保守策略（工程阈值，不是保证利润）：

- **高价值低价**：同一标准商品、同品相与同版本属性，至少3家不同卖家的单件报价；候选含已知邮费价格不高于这些报价最低值的50%，最低参考≥6000日元且差额≥3000日元。
- **超低单价捆包**：原文数量须与入库数量相符。SHF/SIC/DX腰带至少5件、单件≤800日元；普通figure/sofubi至少5件、单件≤300日元；变身小道具/徽章/食玩/扭蛋/指偶至少10件、单件≤100日元。全部包含已知日本国内邮费。
- 标明“库内同款参考”或“超低单件成本”，没有闲鱼数据不显示假的闲鱼价格，没有利润依据不显示预计净利润。
- 同款参考对比不是已成交价格，不能承诺必然盈利或免除购买前核实。

验证：API相关102项测试通过；其中关闭全部闲鱼开关仍可显示合格存量捆包，同卖家重复报价、品相不匹配、缺邮费、垃圾品、已售出、过期数据均被拒绝。Web相关16项测试通过；API/Web TypeScript检查通过。
