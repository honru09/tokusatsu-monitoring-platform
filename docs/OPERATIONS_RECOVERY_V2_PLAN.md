# 运营台恢复与固定入口

## 顺序

1. 修复并复现最小化窗口（已观测Iconic/IsUnMapped）；重连时还原，不删除浏览器资料。
2. 共享一套运营密码（主站龙/润聊天身份不变），两平台资料继续独立。
3. 登录助手：仅在允许的官方创作者域名读取可见登录字段和二维码截图；账号密码在本机加密保存，验证码由用户填写，不自动读取短信、不解题、不跳过协议/认证。
4. 固定入口与单实例本机隧道守护。健康时复用，连续失败才换隧道，发布最新URL。固定入口需要独立公网托管权限；电脑/Docker离线时不能靠静态按钮唤醒电脑。

## 边界

- 浏览器控制API仅允许restore/home/login-scan/login-fill/login-submit；CDP仅监听容器localhost。
- 控制API用独立随机token鉴权，网关仍验证运营会话/CSRF/Origin；无Docker socket、无任意命令执行API。
- 不把密码/OTP/二维码内容传给AI、写日志或公开静态页面；保存密码不可回读明文，只能清除/替换。二维码截图短期在受保护响应内显示。
- 隧道守护不在每次点击时启动，使用单实例锁、连续健康检查和退避；只管理自己记录的cloudflared进程，不杀其他隧道。
- 稳定入口若欠缺部署授权，交付代码及本机守护并明确未公开，不虚构固定URL。
