# 监控配置与首页分类验收

日期：2026-10-08。范围仅为本轮新增监控配置、首页分类入口及其集成，不代表全站历史需求均已验收。

## 实现

- 工作台的监控页面可新增、编辑、启停关键词，选择平台、扫描间隔、目标分类，立即扫描和匹配现有商品。
- 分类可新建、编辑、选择父分类。无父分类默认“其他商品”，选择父分类继承其商品范围，避免包等非玩具商品被特摄识别规则拦截。
- 首页现有分类抽屉增加“监控分类”，数量读取真实在售数，选择后打开对应商品库。分类筛选包括子分类，服务端保持分页、计数与筛选口径一致。
- 新建关键词期间打开新建分类弹窗，返回后保留关键词草稿；保存失败保留输入并显示后台错误。
- 写入携带管理员 accountId；读取不使用旧缓存；未选择管理员时不开放写入控件。

## 设计理由

- 系统字体、16px输入框：延续已指定的 Apple 界面语言，并避免手机输入自动放大。
- 墨色正文、灰色次信息、蓝色操作：将注意力放在关键词、分类和操作状态，错误单独用红色。
- 关键词使用列表而非卡片堆叠：启停与立即扫描直接位于同一关键词旁，适合日常批量管理。
- 桌面分类位于旁列，手机改为下方独立区域：保持阅读宽度与舒适触摸范围，不缩小桌面布局。
- 只有编辑弹窗使用玻璃材料与阴影：区分编辑层级，列表本身不重复叠加透明材质。
- 放大镜、加号、编辑、扫描与刷新图形：分别对应搜索、新增、修改、运行和更新计划，并保留可访问名称。
- 按压即时反馈、开关短过渡、弹窗短入场：呈现用户操作引起的状态变化；减少动态效果时取消位移和缩放。
- 本组件遵循项目 Apple 空间层级，动效不增加循环装饰；父级全站视觉强度仍由既有设计系统负责。
