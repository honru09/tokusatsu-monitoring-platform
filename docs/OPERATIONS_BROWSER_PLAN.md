# 本机运营台

用户选择使用现有电脑，不购买云资源，不改变系统VPN/代理或声称固定东京IP。两平台首登/验证码由用户完成，不导出既有个人浏览器Cookie。

## 技术与信任边界

- 工作台 → 运营台 → 同源受保护的运营服务。运营密码独立于龙/润身份选择。
- 独立Node入口将 /operations-browser/* 路由到运营网关，其他流量仍到现有Next服务。原3000入口保留为反向代理，Web主服务改为内部访问，不动数据库/Redis。
- Chromium两个独立容器与D盘数据目录。只共享用户明确上传的素材，不挂载主机桌面、Keys、Docker socket或项目目录。
- noVNC传输实际远程桌面；每个平台同一时刻一位运营控制，离开释放控制而不关浏览器。
- 浏览器网络internal；Squid仅允许公网HTTP/HTTPS，拒绝本机、私网和metadata地址。无TLS解密、不装代理证书。代理由本机发出流量，与“东京固定出口”无关。
- Chromium非root、只读根FS、drop全部capabilities，保存目录单独写入。采用Playwright官方默认拒绝seccomp样例，补充现代libc兼容调用与无特权内层沙箱所需chroot；保留用户命名空间与Chromium自身沙箱，不使用--no-sandbox或SYS_ADMIN。此配置不是绝对安全承诺。
- 服务端scrypt口令散列、Opaque HttpOnly Secure SameSite cookie、CSRF+Origin校验、限速、过期/退出回收WebSocket。WebSocket与素材API同样鉴权，未认证看不到浏览器画面。
- 初始高强度运营口令由初始化程序生成在.private-operations，仅提供本地路径，不写日志/源码，不覆盖已有口令。

## UI

继承Apple字体、玻璃工具栏和现有导航。平台切换/素材入口/连接状态围绕浏览器，不堆说明。
完整状态：未登录、连接中、已连接、被占用、离线、上传进度、失败重试、退出。
桌面大画布+素材侧栏；手机可展开侧栏及全屏。中文粘贴提供明确按钮，不自动读剪贴板。
文件分块上传避免临时公网入口单请求大小限制，服务端限制总容量/扩展名/路径/大小，不自动发布。

## 验收

鉴权绕过、错误口令、CSRF、WS Origin、并发占用、文件路径/大小/偏移、会话退出；实际RFB画面与官方登录页；浏览器本地存储重启持久化；禁止触达本机私网；匿名远程连接拒绝；主站回归和移动UI检查。
