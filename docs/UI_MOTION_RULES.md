# 整站滚动与交互动效规则

适用于 2026-10-09 整站改版及用户追加的 Apple 画风/动效增强。沿用 motion-tokens.ts、motion/react、现有 GSAP 和 CSS；同一元素只有一个动画所有者。4 / 8px 节奏、浅蓝/薄荷静态 daylight 背景、白色阅读面、磨砂导航及任务优先级是当前视觉基准。ENERGY 3 / RHYTHM 3 / MOTION 3。

| 类型 | 触发与终止 | 适用位置 | 操作与性能规则 |
| --- | --- | --- | --- |
| Scroll-triggered | 首次进入视口触发，播完终止 | 工作台任务区块 | IntersectionObserver；同一挂载内只播一次；最多 18px 位移和 320ms；筛选/刷新不重播全列表；无需动画结束即可操作 |
| Scroll-linked | 映射真实滚动进度 | 长页顶部阅读进度 | 监听实际滚动容器；requestAnimationFrame 合并；transform scaleX；返回恢复、尺寸变化同步；短页/聊天不显示 |
| Parallax | 前背景速度不同，离开区域结束 | 适合大图的展示页或专题首屏 | 仅展示层；最多 8px；禁止采购表格、表单、价格、导航使用；手机、触控与 reduced motion 关闭；本轮工作台无适用区域 |
| Sticky | 区域标题到锚点后吸顶，区域结束释放 | 手机工作台阶段标题、商品库工具栏 | 使用 CSS sticky；尊重 header 与安全区；不能覆盖操作；祖先不能长期保留 transform；短屏检查 |
| Scroll Snap | 原生滚动停止时就近吸附 | 闲鱼图片横向缩略图 | 使用 x proximity；保留可见照片、点击和键盘操作；编辑表单、商品列表、订单不得整屏强制吸附 |
| Horizontal Scroll | 展示内容沿横轴移动 | 原生照片条；长目录局部横滚 | 默认原生 overflow-x；仅专题展示经明确设计才允许纵向驱动横移，必须提供原生横滚/按钮/键盘替代；采购操作页保持普通纵滚 |

## 共用交互

- 按压 100–140ms；反馈 140–220ms；工作区/抽屉空间转换 260–420ms或 appleSpatial spring。导航/商品选中用 appleSelection、按压用 applePress；指针切换连续移动，键盘切换即时反馈。较大的抽屉有更长空间路径，退出/再次打开可从当前值重定向。
- 工作区过渡只由一次真实导航触发，不在初始加载或每次请求重播；固定层祖先不保留transform，结束/cancel清理。持续会话与iframe只淡入，不重新挂载。
- Motion/CSS transition 可打断并从当前状态转向；提交立即开始，反馈只跟随实际等待状态。
- 浮层保留 Escape、焦点约束、关闭回焦、滚动锁和安全区。固定层不放进长期 transform 的祖先。
- 新消息仅更新局部。旧消息阅读位置保留；加载动画和请求等待绑定。
- reduced motion 下取消位移、弹跳、视差和自动滚动；保留即时状态、正常滚动和全部操作。
- 长列表不用逐项滚动测量或全表 layout 动画。scroll 监听 passive，监听器、observer、rAF 均在卸载时清理。

## 验收

320 / 390 / 768 / 1280 / 1440px；手机短屏；normal/reduce；键盘、连续点击、长列表、返回与滚动恢复。验证脚本禁止真实模型、发布、采购、付款或消息写入。闭环指 UI 和状态链路完整，外部成交仍按现有官方确认流程执行。

## Apple 第二轮交互深化

- 输入方式由 AmbientMotionState 在 document capture 层共享。普通控件的按下材质光以实际触点为中心；释放、取消、失焦、页面隐藏时清理。只改变局部材质，不为固定层祖先增加 transform。
- 系统蓝填色为 #0071e3；浅蓝材质上的小号蓝色文字使用 --ui-accent-ink #0066cc。对比度在过渡结束后以实际渲染背景取样，避免只用白底理论值。
- 使用 Motion 的控件声明 `data-apple-motion-owned`；共享按下反馈跳过这些控件。同一控件的 transform 始终由原组件负责。
- 导航保留稳定按钮和同一个选择轨，悬停材质连续迁移；首帧位置取初始工作区，后续变化由单一动画所有者驱动。键盘选择和减少动效即时完成，键盘不会触发按压缩放。
- AppleActionRail 的光感表面跟随实际悬停行。仅 fine mouse 使用，目标变化时测量；文字、数字与按钮位置保持稳定。键盘和 reduce 隐藏光感移动。
- 图片确认加载并解码后再切换；前后方向与操作一致。快速反向操作取消未完成切换，缩略图和画廊操作阻止卡片详情事件。
- 展开区域可从当前高度反向收起。原生 details、箭头、表单反馈在键盘和 reduce 下即时更新；支持性不足的浏览器保留原生展开功能。
- 手机闲鱼工具抽屉采用直接拖拽，取消时回弹，达到阈值下滑关闭；结束后恢复滚动并归还原入口焦点。表单正常纵滚不会启动抽屉手势。
- 保存、收藏、加入采购、物流计算和备注的反馈绑定真实 promise。连续提交使用同步请求锁；失败保留草稿，旧响应不覆盖新输入；成功收到响应后显示回执。
- 消息引用定位只影响相应内容，新回答不抢旧内容阅读位置。运营重连只确认已发送请求，并保留同一个 iframe。
- 录屏和截图等待视口内商品图片完成解码。交互验收使用隔离数据与 route 夹具，不消费真实 AI 额度或写入外部业务。
